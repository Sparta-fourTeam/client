# PNG UI 파츠 분리 작업 — #228

이슈: https://github.com/Sparta-fourTeam/client/issues/228  
브랜치: `chore/228-png-ui-parts` (`origin/dev` 기준)

## 현재 상태

**준비 중이며 게임 화면에 적용하지 않았다.** 기존 PNG를 참고해 투명 파츠 아틀라스 3종을 만들고, 카드 표시 코드와 재바인딩 테스트를 준비했다. 새 PNG의 SpriteImporter 분할, 에셋 표 연결, 프리팹 저장, Unity 컴파일·테스트·플레이 검증은 남아 있다.

Unity CLI가 이 프로젝트에 대해 `STATUS_PIPELINE_LOAD_PENDING`을 반환한다. 샌드박스 밖에서도 같다. 다른 프로젝트의 연결은 있지만 이 프로젝트의 서버가 응답하지 않는다. Unity UI 접근도 `AXError.cannotComplete`로 실패했다. 현재 열린 에디터의 응답과 연결을 복구한 뒤 적용한다.

PSD는 제외한다. 기존 시트와 스프라이트 GUID/fileID를 유지하며 새 파츠를 별도로 연결한다. 원본 파일을 덮어쓰지 않았다.

## 파츠 초안

이미지 생성 도구로 원본을 참고해 분리·복원한 초안이다. 원본 픽셀을 그대로 추출한 결과가 아니므로 실제 적용 전에 작은 화면에서 형태와 손그림 질감을 비교해야 한다.

| 파일 | 배열 (위에서 아래, 왼쪽에서 오른쪽) | 용도 |
|---|---|---|
| [UiSkillParts.png](../Assets/_Project/Sprites/UiSkillParts.png) | 3×3: 화살/불/번개, 회색 원/청색 원/원 테두리, 회색 사각/흰 사각/사각 테두리 | 카드 문양과 상태별 바탕, 공용 프레임 |
| [UiMenuParts.png](../Assets/_Project/Sprites/UiMenuParts.png) | 3×4: 책/인물/퀘스트, POST/종이/날개 달린 지폐, 클로버/캐릭터/집, 잠금 X/메뉴/뒤로 | 메뉴·탭 문양과 잠금 표시. 뒤로 화살표는 생성 후보이며 기존 공용 화살표 교체는 필요 없음 |
| [UiPopupParts.png](../Assets/_Project/Sprites/UiPopupParts.png) | 2×3: 닫기 X/회색 바탕, 노란 프레임/청색 질감, 노란 모서리 장식/검은 프레임 | 닫기 버튼, 창의 질감·테두리·장식 |

세 파일은 RGBA이며 알파 0인 영역이 존재한다. 원형/사각 프레임 중심의 투명함은 픽셀 샘플로 확인했다. 팝업 PNG의 투명한 픽셀에 밝은 RGB가 남아 있어 알파를 무시하는 미리보기에서는 발광처럼 보일 수 있다. 여백의 미세한 알파와 필터링 가장자리는 Unity 렌더링에서 추가 확인해야 한다. 그 검증 전에는 완성 에셋으로 취급하지 않는다.

## 코드 준비

- `SkillAssetEntry`에 신규/강화 아이콘 바탕과 공용 테두리 필드를 추가했다. `GetCardVisual`이 문양과 함께 반환한다. 기존 합성 아이콘은 추가 필드를 비워 두면 그대로 사용할 수 있다.
- `LayeredIconView`가 문양·바탕·테두리를 별도 Image로 표시한다. 합성/일반 아이콘으로 바뀌거나 아이콘이 없으면 이전 바탕과 테두리를 비우고 문양 크기도 복원한다.
- `CardSelectView`와 `CardSlotView`가 새 표시 정보를 전달한다. 프리팹 연결 전에는 기존 Image 경로로 동작한다.
- `LayeredCardIconTests`에 신규→강화→일반→없음→신규의 재사용과 fallback의 잘못된 바탕 혼합을 검사하는 두 테스트를 준비했다. **아직 실행하지 않았다.** `git diff --check`만 통과했다.

## Unity 연결 후 진행 순서

1. 새 PNG를 Sprite/Multiple, 밉맵 꺼짐, 알파 투명 설정으로 임포트한다. Sprite Editor 데이터 제공자의 기능 지원을 확인하고 분할을 저장한다. 생성 아틀라스에 여백이 있으므로 실제 문양의 위치를 확인해 사각형을 잡는다. 원형 바탕·테두리는 중심과 표시 크기를 맞춘다.
2. `SkillAssetTable`의 기존 화살/불/번개 카드 연결을 독립 문양으로 바꾼다. 신규 바탕은 청색, 강화 바탕은 회색, 테두리는 같은 원형 프레임을 쓴다. 현재 같은 그림을 공유하는 다른 스킬은 기존 그룹을 유지한다. 새 스킬 6종 제작은 이 이슈의 범위가 아니다.
3. `CardSelect`의 각 WeaponIcon에 바탕·테두리 Image와 `LayeredIconView`를 연결한다. 장식 Image의 Raycast Target은 끈다. 아이콘 없는 일반 카드도 확인한다.
4. 실제 메뉴 그림은 `Lobby` 씬의 프리팹 재정의에도 있으므로 `NavTab` 원본만 바꾸지 않는다. 정상 문양을 공유하고 배경·프레임·잠금 X를 자식 Image로 구성해 일반/선택/잠금 상태를 확인한다. 메뉴 위치와 클릭 참조를 유지한다.
5. 기존 닫기 X와 팝업 프레임이 연결된 UI에서 질감·테두리·장식을 분리한다. 기존 독립 코인(`6-sheet_1`)과 단일 하트(`4-sheet_8`)를 재사용한다.
6. Unity 컴파일, 두 EditMode 테스트, 카드 재바인딩, 메뉴 상태 전환, 팝업 반복 열기/닫기, 모바일 가독성과 가장자리를 확인한다.

Unity 직렬화 파일은 [프로젝트 규칙](conventions.md)에 따라 Unity에서 저장한다. 새 파일의 `.meta`도 Unity가 생성해야 하므로 연결 전에는 커밋하지 않는다.

## 생성 명세

공통: 기존 시트의 손그림 형태·색·질감을 유지하고, 합성된 바탕과 표시를 분리한다. 실제 RGBA 투명도, 파츠 간 여백, 라벨·격자·그림자 없는 출력. 가려진 부분은 정상 상태 그림과 주변 질감을 참고해 보수적으로 복원한다.

- 스킬: `2-Sheet.png`의 큰 화살/불/번개에서 원형 바탕을 제거한다. 회색/청색 원형 질감, 투명 원 테두리, 회색/흰 사각 바탕과 투명 사각 테두리를 각각 별도 칸에 둔다.
- 메뉴: `2-Sheet.png`의 책/인물/퀘스트/POST/종이/지폐/클로버/캐릭터/집에서 사각 바탕과 프레임을 제거한다. 잠금 X와 메뉴 표시를 별도 칸에 둔다. 흰 문양 내부는 불투명하게 유지한다.
- 팝업: `4-Sheet.png`의 닫기 X와 회색 바탕을 분리한다. 아래 팝업의 노란 프레임·청색 질감·모서리 장식을 분리하고 위 패널의 검은 프레임도 독립시킨다. 추가 수정 명세는 발광·그림자·색 번짐 제거와 프레임 중심의 완전한 투명도였다.
