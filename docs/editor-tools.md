# 에디터 도구

사람이 반복해서 하는 작업을 줄이는 도구만 `Tools > Project Nova`에 둔다. 새 창은 UI Toolkit의 UXML·USS로 구현한다. 에셋을 자동으로 대량 수정하는 기능은 포함하지 않는다.

| 메뉴 | 필요한 작업 |
|---|---|
| Play From Boot | 어느 씬을 편집 중이든 정상 부팅 흐름으로 재생. 프로젝트별 선택 유지. |
| UI Workspace | 로비·전투·공통 프리팹 검색·편집, 구성 안에서 배치 미리보기, 문제 객체로 바로 이동. |
| Playtest | 실제 전투 입장·일시정지·포기·패배·카드 선택·제출 실패와 재시도, 세이브 폴더 확인·백업 후 초기화. |
| Skill Sandbox | 스킬을 독립 씬에서 빠르게 시험. 기존 샌드박스 조작 패널 유지. |

UI Workspace의 미리보기는 저장이나 API를 실행하지 않는다. 원래 프리팹을 변경하지 않는 Preview Scene을 사용하며, 재생 중에는 비활성화된다. 미리보기 수치·아이콘은 기본값이며 실제 Game 뷰의 데이터와 입력 검증을 대신하지 않는다.

Playtest는 상태별로 가능한 조작만 켠다. 표시만 바꾸는 임의 메시지는 발행하지 않는다. 결과 제출 실패 설정은 Local 백엔드에만 적용되고 실패 횟수가 소진되거나 해제될 때까지 유지된다. 세이브 초기화는 재생을 종료한 상태에서만 가능하며, 같은 폴더에 `.bak` 파일을 남긴다. 복원하려면 재생을 종료하고 백업 파일을 `save.json`으로 복사한다.

## 삭제 기준과 결과

| 정리한 도구 | 이유 / 대체 |
|---|---|
| 씬 UI 이전·스냅샷 통합·계층 덤프 | 이전 완료. 반복 실행할 작업이 아니므로 삭제. |
| HUD Preview·개별 Preview 창·일괄 PNG 출력 | 중복 기능. UI Workspace에서 선택한 화면 확인·PNG 저장. |
| UI 검사 메뉴·고정 Generated Artwork 검사 | 로그를 찾아 읽거나 고정된 제작 목록에 의존. UI Workspace의 클릭 가능한 검사로 통합. |
| Message Debugger | 화면과 실제 상태가 달라질 수 있음. 실제 서비스 조작인 Playtest로 교체. |
| 세이브 열기·삭제 메뉴 | Playtest에 통합하고 초기화 전 백업 추가. |
| 몬스터 애니메이션 전체 베이크 | 현재 Attack/Die 구조와 불일치. Unity Animation·Animator에서 원본 편집. |
| 고정 목록 몬스터 Visual 전체 연결 | 새 몬스터마다 코드 수정이 필요하고 기존 Visual을 덮어씀. Prefab Mode에서 선택한 프리팹만 편집. |
| 별도 EditMode 실행 메뉴 | Unity Test Runner와 중복. 기본 Test Runner 사용. |
| 제작 기록의 생성·복사·연결 Python 스크립트 7개 | 이미 끝난 에셋 제작을 위한 일회성 코드. 제작 결과와 기록은 유지. |

CI 빌드 진입점과 스킬 요구사항 검증기는 배포·데이터 변경 검증에 사용하므로 유지한다. Unity 기본 도구와 서드파티 패키지의 Inspector는 프로젝트 전용 메뉴 정리 대상에 포함하지 않는다.

## 확인한 범위

EditMode 테스트 836개 통과. UXML·USS를 Unity에서 임포트하고 실제 EditorWindow에서 로비·전투·공통 목록 전환을 확인했다. UI 검사에서 바인딩된 상태 문구와 대체된 잔여 문구를 구별하며, 저장 초기화는 원본 바이트를 보존한 서로 다른 백업을 만든다. 구성 미리보기 4종은 렌더링되고 원본 프리팹을 수정하지 않는다. 미리보기 Canvas 크기는 휴대폰·긴 화면·태블릿에서 Unity Screen Space Camera의 CanvasScaler 결과와 일치한다. Playtest 버튼으로 실제 씬 왕복·일시정지·재개·포기·제출 오류·재시도를 확인했다. 테스트 결과와 PNG는 `Logs/ToolChecks`에 보관한다.
