# 테스트 유지 기준

EditMode 테스트는 실행에 따른 상태 변화, 이벤트, 외부 부작용을 검증한다.

- 전투 진행: 웨이브 전환, 클리어·실패의 단일 판정, 일시정지, 카드 선택과 제출 재시도.
- 공격 실행: 실제 적중·빗나감, 상태이상 적용·만료, 자식 시전, 풀 재사용과 정리.
- 데이터 보존: 저장 재로딩, 재화 차감·보상, 중복 요청, 거절·오버플로 시 부분 변경 방지.
- API 동작: 요청 전송·인증, 잘못된 응답 거절, 오류 분류와 취소.
- 화면 동작: 이벤트에 따른 표시 전환, 연속 입력, 애니메이션 진행, 재사용 시 표시 복원.

계산 결과를 고정된 기대값과 비교하는 스탯·밸런스·표시 수치 검사, DTO 필드 복사, getter·기본값, 카탈로그와 프리팹·아이콘 연결 대조, 골든 파일은 유지하지 않는다. 동작 테스트에 섞인 단순 설정값 대조도 제거한다. 삭제한 테스트에만 쓰이던 케이스 소스와 헬퍼도 함께 정리한다.

숫자 assertion 자체를 금지하지는 않는다. 공격 후 HP 감소, 중복 요청 시 한 번만 차감, 이벤트 발생 횟수처럼 실행 결과를 확인하는 assertion은 유지한다. 독립적인 실패 경로와 경계 조건도 실제 동작을 검증하면 유지한다.

밸런스·에셋·레이아웃을 바꾼 뒤에는 Skill Sandbox와 해당 화면에서 직접 확인한다. 새 회귀 테스트는 설정값을 복제하는 대신 구체적인 실행과 관찰 가능한 결과를 담는다.

## 실행

```sh
unity test . --mode EditMode --output /private/tmp/nova-editmode-tests.xml --timeout 1200
```

반드시 정리한 브랜치의 worktree에서 실행한다. 결과 XML에서 실패가 없는지와 예상한 테스트가 발견됐는지 함께 확인한다.
