# 얼음창 구현 범위와 검증

## 구현

- 인술 ID 4, 최초 습득을 제외한 전투 강화 상한 15회.
- 최초 구현 활성 카드 6개: 연발, 피해 증폭, 극한의 얼음창, 관통, 헤비 얼음창, 일제 사격.
- 연발은 영구 레벨 5에서 같은 카드의 (+) 명칭으로 바뀌며 공격력 감소가 사라진다.
- 연발 → 일제 사격 → 관통 순서는 허용한다. 일제 사격 이후 연발, 관통 이후 일제 사격은 후보에서 제외한다.
- 얼음창 보유 시 쿠나이 관통 강화 후보를 활성화한다.
- 극한의 얼음창 적중 시 2초 빙결로 이동과 공격을 정지한다. 재적용은 남은 시간과 새 지속 시간의 큰 값을 사용하며 합산하지 않는다. 전투가 정지하면 지속 시간도 진행하지 않는다.
- 투사체 재사용 시 빙결 설정을 초기화한다.

## 검증

Unity 6000.6.3f1 CLI, 격리된 검증 프로젝트에서 EditMode 테스트 **338/338 통과**, 실패·건너뜀 0.

결과: 작업 공간 `outputs/unity-status-results.xml`.
추가 검증은 빙결 이동·공격 정지와 만료, 잘못된 지속 시간, 투사체 풀 재사용, 프리팹 연결, 카드 선택 순서 및 쿠나이 교차 선행조건을 포함한다.
요구사항 검증기도 15개 인술, 168개 원문 카드, 22개 런타임 매핑을 통과했다.

## 남은 작업

- 삼각 얼음창은 아래 두 단계 분열 구현으로 활성화했다.
- 얼음창 영구 성장의 실제 서버 식별자는 아직 없다. progressionId는 null이며 기본 영구 레벨은 0이다. 따라서 영구 레벨 13의 일제 사격은 실제 성장 데이터 연결 전 일반 전투에서 해금되지 않는다.
- 기본 수치는 임시로 쿠나이 기본값을 재사용한다(prototypeBalanceSourceId=1). 전용 기본 밸런스와 성장 비용을 확정한 값으로 간주하지 않는다.
- 아이콘은 기존 화살표를 재사용하고 투사체는 기존 ID 4 프리팹에 청색을 적용했다. 전용 아트와 실제 플레이 검증이 필요하다.
- 고속 투사체는 프레임 이동 구간을 검사한다. 후보 수를 4체로 제한하지 않고 경로상의 가까운 순서로 적중한다. 전체 적 목록 조회·정렬의 성능은 다수 적 플레이에서 확인해야 한다.

## 분열 추가

- 분열과 소형 피해 증폭을 활성화하여 얼음창 활성 카드는 8개가 되었다.
- 사용자 확인에 따라 소형 기본 피해는 본체 현재 피해의 50%를 임시로 사용한다. +80% 증폭은 소형 피해에만 적용한다.
- 본체 적중마다 소형 얼음창 3개를 생성한다. 소형은 재분열하지 않고, 생성 원인인 적은 다시 타격하지 않는다.
- 발사 방향 기준 -30/0/+30도, 프리팹 크기의 50%, 본체 속도, 3초 수명은 임시 시각·발사 설정이다.
- 소형에 본체의 빙결·관통을 자동 전파하지 않는다. 소형 동상은 별도 미구현 카드이다.
- 풀에서 본체를 다시 얻으면 원래 크기로 복원하고 적중 콜백·무시 대상도 매번 초기화한다.
- 새 테스트는 프레임 사이 적중/경로 밖 미적중, 소형 3개와 독립 피해·재분열 방지를 검증한다.

## 충격·동상 추가

- 얼음창 충격(+200% 밀침, 관통 +2), 사무치는 냉기, 스며드는 냉기를 활성화한다. 얼음창 활성 카드는 11개다.
- 사용자 확정 임시값: 본체 기본 밀침 0.2 Unity 단위, 충격 강화 후 0.6. 소형에는 밀침·관통을 자동 전파하지 않는다.
- 사용자 확정 임시값: 적중 투사체 피해의 10%를 중첩당 1초마다 적용, 10초 유지, 최대 5중첩. 소형은 소형 자체 피해를 기준으로 한다.
- 각 중첩은 독립적인 타이머·피해 스냅샷을 가진다. 상한에서 새 적용은 가장 오래된 중첩을 교체한다. 전투 정지에는 타이머를 진행하지 않는다.
- 지속 피해는 정수로 버림하되 양수 피해는 최소 1이다. 큰 프레임 시간에도 활성 기간의 모든 주기를 처리하며 사망 발행은 한 번만 일어난다.
- 분열·동상·충격의 수치와 상태 시각 효과는 실제 플레이 밸런스 검증이 필요하다.

## 삼각 얼음창

- 관통·극한의 얼음창·피해 증폭 선행, 최대 1회. 삼각 본체가 적중하면 일반 얼음창을 생성하고, 일반 얼음창은 다시 삼각으로 변하지 않는다.
- 개수·피해 자료가 없어 답변 대기 중인 임시 제안값으로 일반 3개·삼각 본체 피해의 50%를 사용한다. 방향 -30/0/+30도, 본체 속도·3초 수명, 본체 관통·빙결·밀침·동상 및 각각의 발동률을 유지한다.
- 별도 얼음창 분열을 선택하면 일반 얼음창 적중 시 소형 3개가 생성된다. 소형 피해는 생성한 일반 얼음창 피해의 50%에 소형 피해 증폭을 곱한다. 소형 동상은 스며드는 냉기 선택 시 적용한다. 본체 상태를 소형에 자동 전파하지 않는다.
- 삼각에서 직접 소형을 만들거나 일반에서 삼각을 생성하지 않는다. 각 단계는 생성 원인인 적을 무시하고, 소형은 재분열하지 않는다. 삼각 자체의 관통으로 여러 적을 맞히면 적중마다 일반을 생성한다.
- 삼각 외형은 청색 삼각 테두리 프로토타입이다. 일반·소형으로 풀 재사용 시 원래 스프라이트를 복원한다. 전용 아트·플레이 검증과 얼음창의 실제 영구 성장 ID 연결은 남아 있다.

삼각 얼음창 검증: Unity 6000.6.3f1 CLI 컴파일·EditMode 388/388 통과, 실패·건너뜀 0. 결과: 작업 공간 outputs/unity-triangle-ice-results.xml. 요구사항 검증 15개 인술·168개 원문 카드·56개 활성 런타임 매핑 통과.
