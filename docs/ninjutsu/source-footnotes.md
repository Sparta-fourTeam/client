# 사용자 추가 제공 각주

사용자가 붙여 넣은 위키 각주 중 인술 요구사항에 관계있는 내용만 정리했다. 링크 페이지를 새로 조회한 내용이 아니라 제공된 본문을 근거로 한다. 자료에 없는 다른 카드의 디버프 제거 조건을 추론하지 않는다.

| 각주 | 대상 / 규칙 |
|---|---|
| 6 | 다단계 선행조건 표에는 가장 마지막 조건만 적혀 있다. 선행조건 그래프를 따라 이전 조건이 성립한다. |
| 7 | 쿠나이 일제 사격: 영구 9레벨에 + 명칭으로 바뀌고 공격력 -20%가 사라진다. |
| 증폭 | 두 인술 보유로 등장하는 증폭/연마 선택은 양쪽 인술의 습득 수를 증가시킨다. |
| 10 | 피뢰침은 다중 쿠나이의 각 쿠나이마다 발동한다. |
| 11 | 연발 쿠나이는 공격 자체를 한 번 더 한다. 일제 사격과 함께 여러 쿠나이를 여러 번 발사할 수 있다. |
| 12 | 연발 쿠나이는 영구 17레벨에서 + 명칭으로 바뀌고 공격력 -30%가 +10%로 바뀐다. |
| 13 | 쿠나이 난사와 확산 쿠나이는 양립하여 보조 쿠나이 총 6개를 발사한다. |
| 14 | 연속 화염구Ⅱ: 영구 9레벨에서 + 명칭으로 바뀌고 공격력 -30%가 사라진다. |
| 15 | 얼음창 연발: 영구 5레벨에서 + 명칭으로 바뀌고 공격력 -20%가 사라진다. |
| 16 | 연속 벼락: 영구 9레벨에서 + 명칭으로 바뀌고 공격력 -20%가 사라진다. |
| 19 | 연발 통나무: 영구 5레벨에서 + 명칭으로 바뀌고 공격력 -20%가 사라진다. |
| 22 | 히스이의 비기는 예외적으로 나선 회오리가 아니라 태풍 레벨을 참조한다. 자료에는 향후 수정 가능성이 언급되어 있다. |
| 투사체 | 관통력이 있는 인술로 쿠나이·얼음창·통나무·나선 회오리를 명시한다. |

공격력 변화의 원래 감소 수치는 최초 표를, 전환 레벨과 전환 후 효과는 이 각주를 근거로 연결했다. 각주가 없는 비행 속도 감소·쿨타임 증가 등의 불이익은 그대로 보존한다.

이 각주가 앞선 ‘모두 영구 9레벨’이라는 임시 일반화를 대체한다. 카드 ID와 최대 등장 횟수는 전환 전후에 공유하고, 전환 단계별 피해 보정과 표시명을 따로 둔다. 현재 실행 카드인 쿠나이 일제 사격·연발 쿠나이·연속 벼락에는 변형을 연결했다. 나머지 인술은 카탈로그 추가 시 해당 규칙을 연결한다.
