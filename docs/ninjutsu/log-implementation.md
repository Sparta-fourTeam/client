# 통나무 기본 구현

- 통나무는 인술 ID 5, 최초 습득을 제외한 전투 강화 상한 10회다. 기존 플레이어 ID 5 프리팹 연결을 재사용하여 신규 인술 후보에 포함한다.
- 실제 기본 수치 자료가 없어 쿠나이 프로토타입 기본값을 재사용한다(prototypeBalanceSourceId=1). 피해 10, 쿨타임 1초, 사거리 22, 기본 밀침 0.2. 이동 속도·경로·관통은 아래 교정 규칙을 사용한다. 원본 게임의 확정 수치로 간주하지 않는다. 기본 감속·충격 상태의 임시 수치는 아래 추가 구현으로 연결했다.
- 통나무 피해 증폭은 공격력 +60%, 최대 2회다. 최초 자료 4회와 추가 자료 2회가 다르며 추가 자료의 횟수를 사용한다.
- 연발 통나무는 추가 시전 +1, 공격력 -20%, 최대 2회다. 영구 레벨 5부터 같은 카드가 연발 통나무+로 표시되고 공격력 감소를 제거한다. 선행조건과 횟수 ID는 공유한다.
- 크기 증가는 외형과 적중 반경 +60%, 최대 1회다. 속도 증가는 투사체 속도 +40% 및 쿨타임 -25%, 최대 1회다.
- 연발·크기 증가는 최초 자료의 피해 증폭 선행을 보존했다. 추가 자료에는 기본 강화로 기재되어 있어 두 자료의 차이는 유지한다.
- 투사체 기본 적중 반경 0.3에 크기 배율을 곱한다. 크기 강화 후 0.48이며 재사용 Init에서 기본 반경으로 초기화한다. 기존 인술은 배율 1로 기존 판정을 유지한다.
- 기존 ID 5 투사체를 갈색 장방형 프로토타입으로 바꾸었고 카드/HUD 아이콘은 기존 화살표를 재사용한다. 통나무 전용 아트와 실제 플레이 검증은 남아 있다.
- 실제 영구 성장 식별자는 미확정이므로 progressionId=null이다. 일반 전투의 영구 레벨은 0이며 성장 데이터 연결 전에는 연발+가 실제 프로필로 해금되지 않는다. 임의 성장 비용·서버 ID를 만들지 않는다.
- 예비 통나무는 아직 연결하지 않았다.

## 충격·중량·상처 악화

- 사용자 승인 임시값: 통나무 기본 감속은 30%·2초다. 중량 증가 선택 시 지속 시간 +4초로 6초가 된다. 최대 1회다.
- 충격 통나무는 밀침 +75%, 10% 확률 기절이다. 최대 1회, 승인 임시 기절 지속 시간은 1초. 기본 밀침 0.2 기준으로 0.35가 된다. 기절 확률은 기본 상태 발동률 100% 규칙의 명시적 예외다.
- 기절은 이동·공격을 멈추며 빙결·마비와 별도 타이머다. 재적용 시 남은 시간과 새 시간 중 긴 값을 사용한다. 감속은 이동속도만 바꾼다.
- 통나무 감속과 영역 감속은 가장 강한 비율만 적용한다. 통나무 감속은 중첩하지 않고 강한 값·긴 시간으로 갱신하며 만료 시 복구한다. 영역이 사라져도 통나무 감속은 자기 시간이 남아 있으면 유지한다.
- 상처 악화는 최대 1회, 받는 피해 +20%·6초다. 타격 피해를 준 뒤 적용하므로 최초 통나무 타격에 자기 보너스를 소급하지 않는다. 이후 일반 타격·폭발·벼락·전자기장·점화·동상 등 모든 적 모델 피해에 적용한다.
- 상처 악화는 가장 강한 비율·긴 시간으로 갱신하며 합산하지 않는다. 정수 입력 피해에 배율을 곱한 뒤 내림한다. 큰 상태 갱신 시간은 상처 악화 만료 경계에서 나누어 만료 후 지속 피해에 보너스가 남지 않게 한다.
- 사망 시 새 상태들을 비우며 투사체 재사용 시 기절 확률·지속 시간·감속·상처 악화 설정을 초기화한다. 전투 정지에는 상태 시간이 진행하지 않는다.
- 기절·감속·상처 악화 전용 시각 효과와 실제 플레이 밸런스 검증은 남아 있다.

상태 효과 추가 검증: Unity 6000.6.3f1 CLI 컴파일·EditMode 401/401 통과, 실패·건너뜀 0. 결과: 작업 공간 outputs/unity-log-status-results.xml. 요구사항 검증 15개 인술·168개 원문 카드·63개 활성 런타임 매핑 통과.

## 대형·화염 통나무

- 대형 통나무: 크기 증가·충격 통나무·중량 증가 선행, 최대 1회. 공격력·크기·밀침 각각 +60%. 중량 증가 조건은 추가 자료의 상세 트리를 따르며 최초 자료에는 생략되어 있다.
- 퍼센트 강화는 기존 배율 방식으로 곱한다. 피해 증폭 1회·크기 증가·충격 통나무 후 대형 선택 시 임시 기본값 기준 피해 25.6, 크기 배율 2.56, 적중 반경 0.768, 밀침 0.56이다. 대형 자체가 기절 확률·감속 시간·공격 주기를 추가 변경하지 않는다.
- 화염 통나무: 화염구 보유·크기 증가·통나무 피해 증폭 선행, 영구 인술 레벨 9, 최대 1회. 피해 증폭 선행은 추가 자료를 따른다. 성장 ID는 여전히 미확정이므로 일반 전투의 영구 레벨 해금에는 실제 성장 데이터 연결이 필요하다.
- 화염 점화는 기존 승인 임시값을 재사용한다: 직격 피해의 10%를 1초마다, 6초 지속, 기본 발동률 100%, 비중첩·재적용 갱신. 폭발로 점화를 적용하지 않으며 화염 통나무에 별도 폭발 효과를 추가하지 않는다.
- 두 형태는 양방향 배타다. 어느 쪽을 먼저 선택하든 다른 쪽은 후보에 등장하지 않는다. 기절·감속·상처 악화·연발·속도 등 이미 선택한 강화는 유지한다.
- 대형은 실제 크기·적중 반경 증가로, 화염은 주황색 스프라이트로 형태를 표시한다. 풀 재사용 시 크기·색상·점화·상태 설정을 복원한다. 전용 통나무·화염 아트와 실제 플레이 검증은 남아 있다.

## 구르는 경로 교정

- 기존 구현은 쿠나이처럼 플레이어 위치에서 적을 향해 대각선 투척했고 속도 20·수명 3초·첫 적중 후 반환을 재사용했다. 사용자 정정에 따라 이 통나무 발사 방식을 교정했다.
- 사용자 확인 경로: 선택한 적의 x좌표, 플레이어 발사선의 y좌표에서 생성하고 위쪽으로 수직 직선 이동한다. 생성 후 적을 추적하거나 대각선 방향을 갱신하지 않는다. `ProjectilePath.RollingLane`으로 분리해 쿠나이·얼음창의 조준 투척은 유지한다.
- 사용자 승인 임시 기본 속도는 4 Unity 단위/초다. 속도 증가 후 5.6이다. 원본 게임의 확정 속도는 아니다.
- 구르는 통나무는 첫 적중에서 종료하지 않고 경로상의 여러 적에게 피해·밀침·감속·선택한 상태 효과를 적용한다. 한 통나무는 같은 적에게 중복 피해를 주지 않는다. 통나무 경로는 일반 투사체의 관통 수와 분리한다.
- 느린 속도에서 기존 3초 수명으로 조기 종료하지 않도록 사거리/현재 속도 +0.1초의 임시 수명을 사용한다. 시전 시점의 속도·수명을 저장한다.

- 원문 토둔술의 비행형 적 제외는 적 모델에 비행 분류가 없어 아직 연결하지 않았다. 전용 굴러가는 아트·애니메이션과 플레이 검증은 남아 있다.
