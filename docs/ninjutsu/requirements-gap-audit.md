# 인술 요구사항과 현재 구현 대조

2026-10-05 기준. 대상은 `work/ProjectNova`의 `codex/ninjutsu-refactor` 작업 내용이다. 이번 정리에서는 코드를 변경하지 않았다. 이전 결과 문서보다 이 문서의 확정 여부와 구현 상태를 우선한다.

자료에서 확인한 규칙과 사용자가 직접 확정한 규칙은 구분했다. 새 자료에서 빠진 기존 제한은 명시적으로 철회된 것으로 간주하지 않는다. 두 자료가 충돌하는 항목은 최종 규칙을 확정하기 전까지 미확정이다.

## 현재 구현과의 차이

| 요구사항 | 현재 상태 | 차이 / 영향 |
|---|---|---|
| R01 영구 레벨 | 전투/영구 레벨 필드와 판정 경로는 분리됨. 기존 로비 ID에 임시 연결됨. | 실제 영구 인술 성장 레코드와 ID 계약이 없음. 실행 JSON에도 영구 레벨 조건이 아직 없음. 실제 해금 동작은 완료되지 않음. |
| R02 최대 등장 횟수 | 성공한 선택만 카운트하고 한도에서 후보 제외. 실패 시 재선택 처리. | 기반 구현 완료. 전체 인술의 횟수 데이터 반영과 Unity 통합 검증은 남음. |
| R03 선행조건 | 다른 인술 보유, 강화 횟수 등 판정 기능 있음. 일부 쿠나이 선행 강화만 실행 데이터에 연결됨. | 조건 지원과 전체 조건 적용은 다름. 잘못된 참조·순환 등 카탈로그 의미 검증도 부족함. |
| R04~R06 배타·순서 | 조건 판정기와 예제 테스트 있음. | 실제 실행 JSON에는 배타 조건이 없음. 자료의 실제 선택 규칙이 아직 동작하지 않음. |
| R07 효과 분리 | 발사/시전/관통/이동 속도를 분리함. 반복 시전과 관통 이력 구현. | 동시 발사 방향, 반복 간격, 공격별 명중 방식은 요구사항과 추가 대조 필요. 관통 강화는 얼음창 미연결로 비활성. |
| R08 분류·대상·시간 | 시전 형태는 Projectile/Hitscan 2개. 현재 타이머는 즉시 쿨타임 방식. | 6속성·4형태·공중 필터·지속 종료 후 쿨타임 미구현. |
| R09 복합 효과 | 수치 강화와 기본 시전 기반만 구현됨. | 폭발·분열·점화·빙결·마비·동상·기절·처치 발동·변형·계열 증폭 미구현. |
| R10 범위 | 초안은 15종 원문 보존. 실행 데이터는 쿠나이·화염구·벼락 3종, 강화 정의 9개 중 활성 8개. | 나머지 12종과 대부분 강화는 실행 데이터 및 전투 효과가 없음. 원문 보존은 구현 완료가 아님. |
| 데이터 통합 | 새 Weapons.json을 별도 Resources 경로에서 로드함. 기존 Cards.json도 남아 있음. | 단일 카탈로그 및 기존 GameDataStore 계약으로 통합되지 않음. 같은 정보가 갈라질 위험이 있음. |
| 검증 | 별도 .NET 환경에서 소스 컴파일 및 순수 로직 23건 통과. | Unity EditMode 실행은 프로젝트 중복 실행으로 차단됨. 플레이·프리팹·UI·실제 영구 성장 검증 미완료. |

## 제가 먼저 적용한 미확정 사항

1. **‘최대 레벨’을 전투 상한으로 해석했다.** 실행 데이터에 쿠나이 15, 화염구 14, 벼락 14를 적용했다. 사용자가 확정한 것은 해금 조건의 영구 레벨 의미이며, 이 상한의 의미는 확정하지 않았다. 이전 2단계 문서의 ‘최대 전투 레벨 적용’은 확정된 요구사항처럼 읽힐 수 있어 정정한다. 현재 레벨은 1에서 시작하고 성공한 카드 선택마다 1 증가하므로 상한 15는 강화 14회 제한으로 동작한다.
2. 연발 간격 0.1초는 프로토타입 설정이다. 원문 수치가 아니다.
3. 연발 쿠나이/연속 벼락은 피해 감소가 있는 일반 표기를 선택했고, 추가 자료의 (+) 변형을 별도로 구현하지 않았다. 두 표기의 관계는 미확정이다.
4. 기본 공격력·사거리·쿨타임 등은 기존 프로토타입 수치를 유지했다. 자료 기준 최종 밸런스가 아니다.
5. 공격력 증가와 쿨타임 감소는 기존 방식대로 순차 곱연산을 유지했다. 합연산/곱연산 기준은 요구사항으로 확정하지 않았다.
6. 쿠나이 일제 사격의 공격력 -20%는 최초 자료를 유지했다. 추가 자료의 생략이 삭제를 뜻하는지는 미확정이다.

## 두 자료에서 결정이 필요한 부분

| 항목 | 차이 또는 불명확한 점 |
|---|---|
| 화염구 | 폭발 화염구의 자기 참조는 추가 자료의 ‘폭발 강화’로 해소 가능. 수련 선행조건, 염폭술의 충격 강화 조건, 번지는 화염의 영구 레벨 5 조건은 자료마다 다름. |
| 얼음창 | 추가 자료에 일제 사격 영구 레벨 13 추가. 연발의 공격력 감소 표기 생략. 분열 단계와 기존 효과 유지 범위를 정리해야 함. |
| 벼락 | 피해 증폭 한도 4→3. 뇌전 제재의 영구 레벨 5 생략. 연속 벼락의 (+)/일반 표기 관계 미확정. |
| 통나무 | 피해 증폭 한도 4→2. 크기 증가·연발의 선행조건 변경. 대형 통나무에 중량 증가, 화염 통나무에 피해 증폭 조건 추가. |
| 이름·참조 | 월광 증폭/월광 피해 증폭, 모래 폭탄/모래 폭발의 동일 여부. 전력망 저항의 동명 다른 효과. 캐릭터 이름 및 비취 폭풍의 태풍 레벨 참조 불일치. |
| 광선 | 공격 횟수가 발사 수·공격 틱·지속시간 중 무엇인지 불명확. |
| 최대 레벨 | 전투 강화 상한인지, 다른 의미인지 확인 필요. 기본 습득을 상한에 포함하는지도 결정 필요. |

## 후속 사용자 확정

- 최대 레벨은 최초 습득을 제외한 전투 강화 횟수 상한으로 확정했다. 앞의 미확정 표기는 당시 감사 기록이다.
- 영구 인술 레벨 9부터 명칭에 +가 붙고 공격력 감소가 사라진다. 별도 카드가 아니며 선택 횟수를 공유한다. 다른 디버프의 적용 범위는 확인 중이다.
- 최신 카드별 대응은 requirements.md와 requirements.json을 본다.
