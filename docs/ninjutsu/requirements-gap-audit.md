# 인술 요구사항과 현재 구현 대조

2026-10-05 갱신. 대상은 현재 작업 트리의 스킬 조합 구조 개편이다. 초기 감사 이후의 사용자 확정과 구현을 반영했다. 카드별 근거와 자료 충돌은 requirements.md / requirements.json, 각주는 source-footnotes.md를 참조한다.

## 확정된 규칙

- 해금 조건은 로비 영구 인술 레벨, 전투 상한은 최초 습득을 제외한 성공한 강화 횟수다.
- 최대 등장 횟수는 선택 성공 때만 사용한다. 미선택 제시·실패는 차감하지 않는다.
- 일반과 (+)는 같은 카드와 선택 횟수를 공유한다. 각주가 정한 영구 5·9·17레벨 전환만 적용한다.
- 단방향 제한을 보존한다. 얼음창 연발→일제 사격→관통, 벼락 심판의 천둥→자기 폭풍 순서는 허용한다.
- 기본 상태이상 확률은 100%, 자료의 별도 확률은 우선한다(충격 통나무 기절 10%). 점화는 본체 직접 명중에만 적용하고 폭발에 전파하지 않는다.

## 현재 구현과 남은 차이

| 항목 | 구현 | 남은 작업 |
|---|---|---|
| 영구 성장 | 전투/영구 레벨 분리, 카드별 해금·변형 조건과 UI 연결 | 실제 영구 성장 계약 및 ID 연결. 얼음창·통나무 progressionId=null |
| 선택 조건 | 성공 횟수·강화 상한·선행·배타·선택 순서 제한, 공유 카드 양쪽 갱신 및 중복 후보 방지 기반 | 미구현 인술의 조건 데이터와 실제 공유 카드 활성화 |
| 범위 | 15종·168개 원문 강화 행 보존, 5종·66개 활성 실행 매핑 | 나머지 10종 및 캐릭터 전용 시작 상태 |
| 쿠나이 | 20개 강화 연결 | 쿠나이 폭풍 횟수 확정, 태양/달빛 연계 증폭 |
| 화염구·얼음창·통나무 | 각각 11·12·10개 강화 연결 | 자료 충돌 및 임시 수치 확정, 실제 성장 해금·아트·플레이 검증 |
| 벼락 | 13개 강화, 구체·처치 소형 벼락·심판·전자기장 연결 | 연쇄 번개 연계 증폭·연마, 초기 단일/범위 타격 구분 |
| 분류·시간 | Projectile/Hitscan, 조준/통나무 경로, 별도 전자기장 수명·피해 주기 | 6속성·4형태·지상/공중 필터, 지속 주공격 종료 후 쿨타임. 현재 CastClock은 즉발 기준 |
| 카탈로그 | Weapons.json 런타임, 별도 요구사항 표·검증기 | 기존 Cards.json 및 GameDataStore와의 통합 계약 정리 |
| 리팩토링 | 불변 SkillConfig·효과별 스탯·공격 이벤트·강화 빌더·후보/조건/검증 서비스 분리 | 이전 Init 호환 진입점과 테스트 호출부 전환 여부, 다수 적 조회·정렬 성능 확인 |
| 검증 | [최신 Unity 검증](unity-validation.md), 요구사항 검증 통과 | 프로덕션 선택 UI·영구 성장·최종 시각 효과·다수 적 성능 검증 |

66개 활성 매핑은 실행 연결 수이며 최종 밸런스·전용 아트·실제 성장 연결 완료 수가 아니다. 초기 문서의 ‘3종·9개’, ‘상한/일반·+ 미확정’, ‘Unity 실행 차단’ 표기는 이 상태로 대체한다.

## 남은 결정

- 두 자료의 선행조건·횟수 차이: 화염구 수련/염폭술, 얼음창 일제 사격, 벼락 피해 증폭, 통나무 피해 증폭 및 형태 조건. 현재 선택한 보수적 조건을 카드별 문서에 남겼다.
- 영구 성장 ID·성장 비용, 백분율 합/곱연산의 최종 정책, 기존 프로토타입 기본 피해·사거리·쿨타임.
- 삼각 얼음창 일반 분열 개수·피해는 미확정 제안값이다. 업화/번지는 화염의 세부 임시 규칙과 실제 플레이 밸런스도 검토가 필요하다.
- 광선 공격 횟수의 의미, 월광 증폭 명칭, 모래 폭탄/모래 폭발 동일 여부, 캐릭터 전용 효과 계수·횟수 사용.
- 히스이 비취 폭풍의 성장 참조는 각주에 따라 태풍으로 확정했다. 캐릭터 이름 불일치는 별도 남아 있다.
