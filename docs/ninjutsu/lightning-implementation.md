# 벼락 마비·고전압 벼락

- 벼락 기본 마비 지속 시간은 자료에 없어 조정 가능한 임시 1초를 사용한다. 기본 발동률은 사용자 정정에 따른 100%다.
- 고전압 벼락은 공격력 +30%, 마비 지속 시간 +1.5초, 최대 1회. 임시 기본값 기준으로 피해 25 → 32.5, 마비 1 → 2.5초다.
- 기본 마비와 추가 지속 시간을 구분한다. 쿠나이의 마비 추가는 기존 설정 효과를 유지하고 고전압은 지속 시간 증가 효과를 별도로 사용한다.
- 벼락의 실제 HitscanEffect 적중 이벤트에서 피해 후 적 모델에 마비를 적용한다. 여러 콜라이더를 가진 같은 Enemy는 한 번만 적용한다.
- 발사 시 지속 시간과 확률을 저장하며 이펙트 재사용 시 대상 적중 콜백도 초기화한다. 반복 Hit 이벤트는 중복되지 않는다.
- 기존 벼락 프리팹의 반경 1.5 물리 충돌 판정을 유지한다. 원문의 초기 단일 대상 공격과 범위 공격 전환을 구분하는 타격 방식은 추가 정리가 필요하다.
- 전자기장·고전압 전장·안정된 전장은 별도 문서의 구현으로 연결했다. 연쇄 번개가 필요한 뇌둔술 증폭·연마와 전용 시각 효과·플레이 밸런스 검증은 남아 있다.

## 검증

Unity 6000.6.3f1 CLI EditMode 376/376 통과, 실패·건너뜀 0. 결과: 작업 공간 outputs/unity-lightning-judgement-results.xml. 요구사항 검증 15개 인술·168개 원문 카드·53개 런타임 매핑 통과.

## 전자 분열·고전압 입자

- 전자 분열은 고전압 벼락과 벼락 피해 증폭 선택 후 등장하며 최대 1회다. 실제 벼락 적중 이벤트에서 6방향 구체를 한 번 생성한다.
- 승인된 임시값: 현재 벼락 피해의 50%, 속도 10, 수명 3초. 최초 타격 대상을 제외하고 다른 적에게 충돌하며 추가 분열·폭발·점화를 상속하지 않는다.
- 고전압 입자는 전자 분열 후 최대 1회. 구체 피해 +40%로 벼락 피해의 70%가 되고 0.5초 마비를 적용한다. 기본 구체에는 마비가 없으며 본체의 마비 지속 시간을 상속하지 않는다. 상태 발동률은 기본 100%다.
- 실제 Lightning_Lv1 및 기존 Projectile3 프리팹에 구체 프리팹을 연결했다. 구체 외형은 노란색 소형 투사체 프로토타입이며 전용 아트·실제 플레이 검증은 남아 있다.

## 뇌전 제재·심판의 천둥

- 뇌전 제재: 벼락 피해 증폭 선행, 영구 인술 레벨 5, 최대 1회. 공격력 +150% 및 벼락 직격으로 처치한 적당 소형 벼락 1회. 레벨 5 조건은 최초 자료를 보존한다(추가 자료에는 생략).
- 승인된 소형 벼락 임시 규칙: 처치 위치에서 가장 가까운 생존 적 1명, 탐색 범위는 벼락 기본 사거리, 현재 벼락 피해의 50%. 대상이 없으면 시전하지 않는다.
- 본체 발사 시 피해를 저장한다. 소형 벼락은 기존 벼락 이펙트 크기 50%를 사용하고 적중 시점에 지정 대상만 타격한다. 대상이 먼저 죽으면 타격하지 않으며 재탐색하지 않는다. 추가 분열·폭발·마비·처치 연쇄를 상속하지 않는다.
- 본체는 중복 콜라이더와 반복 Hit 이벤트를 제거하고, 이미 죽은 적을 타격하지 않는다. 본체 직격 처치만 발동한다. 자기 폭풍·번개 구체·지속 피해의 처치는 현재 발동 대상으로 포함하지 않는다.
- 심판의 천둥: 고전압 벼락과 뇌전 제재 선행, 영구 인술 레벨 13, 최대 1회, 공격력 +200% 및 형태 전환. 자기 폭풍을 먼저 선택하면 등장하지 않으며 심판의 천둥 이후 자기 폭풍은 허용한다.
- 심판의 천둥 외형은 기존 벼락 이펙트 크기를 1.5배로 키운 프로토타입이다. 물리 타격 반경은 유지한다. 전용 아트와 실제 플레이 검증은 남아 있다.
- 풀 재사용 시 지정 대상·처치 콜백·크기를 초기화하며 기존 강화 효과는 각각 유지한다.
