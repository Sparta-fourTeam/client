# 기본 점화 구현

- 화염구 점화는 폭발 강화 습득 후 1회 선택한다.
- 화염 쿠나이는 폭발 쿠나이와 쿠나이 강화가 모두 필요하며 1회 선택한다. 전용 형태·아트는 남아 있다.
- 사용자 확정 임시값으로 기본 피해는 적중 투사체 피해의 10%를 1초마다 적용한다. 화염구 자료의 6초 지속을 쿠나이에도 임시 재사용한다.
- 점화는 중첩되지 않는다. 재적용은 지속 시간과 주기 피해를 각각 더 큰 값으로 갱신하며 피해 주기 누적 시간은 초기화하지 않는다.
- 이동·공격은 점화만으로 멈추지 않는다. 빙결·마비 중에도 피해는 진행하지만 전투 정지(deltaTime 0)에서는 시간·피해가 진행하지 않는다.
- 소수 피해는 버림하며 양수는 최소 1이다. 큰 프레임 시간에도 활성 기간에 포함된 모든 주기를 처리한다.
- 본체 직접 적중에만 적용한다. 폭발 범위 피해·보조 쿠나이에 자동 전파하지 않는다.
- 업화와 번지는 화염은 아래 추가 구현으로 연결했다.
- 점화 모델 주기·재적용·만료, 빙결·동상 공존, 사망 발행 1회, 투사체 풀 재사용, 실제 카드 선행조건을 검증한다.

## 검증

Unity 6000.6.3f1 CLI EditMode 356/356 통과, 실패·건너뜀 0. 작업 공간 outputs/unity-burn-special-results.xml. 요구사항 검증 15개 인술·168개 원문 카드·44개 런타임 매핑 통과.

## 업화·번지는 화염 추가

- 두 카드 모두 화염구 점화 선행, 최대 1회. 번지는 화염은 최초 자료의 영구 인술 레벨 5 조건을 유지한다.
- 제안한 임시 규칙으로 업화는 매 점화 주기에 대상 최대 HP의 3%를 기본 점화 피해에 추가한다. 비례 계산은 소수점 4자리로 부동소수점 오차를 보정한 후 전체 피해를 정수로 버린다.
- 번지는 화염은 점화 중 사망하면 발사 당시 화염구 폭발 피해·반경으로 1회 폭발한다. 다른 피해로 죽은 경우도 포함한다.
- 사망 폭발은 새 점화를 적용하지 않는다. 이미 점화된 주변 적이 폭발로 죽으면 각 적의 사망 폭발은 연쇄될 수 있다.
- 점화 마지막 주기로 죽는 경우도 폭발한다. 점화 만료 후 사망은 폭발하지 않는다. 사망 콜백을 먼저 제거하여 같은 적의 재진입·중복 발동을 방지한다.
- 큰 전투에서 긴 사망 연쇄의 성능·콜스택과 시각 효과는 플레이 검증이 필요하다.
