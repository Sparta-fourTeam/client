# 투사체 리팩토링 1단계

- ProjectileSpawnSettings에 생성 시 위치·이동·피해·명중 효과·확률·콜백을 명명된 설정으로 모았다.
- 본체, 삼각 얼음창의 일반 분열, 보조 투사체, 번개 구체의 전투 호출부를 새 설정으로 전환했다.
- Init은 설정 값을 생성 시 복사한다. 생성 이후 설정 객체 변경이 발사된 투사체에 전파되지 않는다.
- 기존 Init은 동일한 새 초기화 경로로 위임하는 호환 진입점으로 유지했다. 기존 테스트와 이전 호출자의 기본값을 보존한다.
- 수치, 효과 상속, 풀 재사용 초기화, 콜백 실행 순서는 변경하지 않았다.
- Unity CLI 컴파일·EditMode 409/409 통과. outputs/unity-projectile-settings-results.xml 확인.
- 다음 단계: 명중 효과 처리 분리, 본체·보조·분열 생성 규칙 분리, 경로·형태 표시 분리. 이전 호출 진입점 제거는 테스트 호출부 전환 후 진행한다.

## 2단계: 명중 효과 분리

- ProjectileHitEffects가 직격 피해·상태이상·추가 벼락 피해를 기존 순서로 적용한다. 생성 시 설정을 복사하고 풀 재사용마다 전체를 교체한다.
- Projectile은 이동·충돌·관통 기록·충돌 위치·임팩트·추가 생성 콜백과 반환을 담당한다. 효과 처리 이후 임팩트와 콜백을 실행하는 순서를 보존했다.
- 기존 분열 효과 스냅샷 테스트 및 확률 테스트의 내부 검사 위치를 분리된 데이터에 맞췄다.
- Unity CLI 컴파일·EditMode 409/409 통과. outputs/unity-hit-effects-results.xml 확인.

## 3단계: 생성 규칙 분리

- ProjectileSpawnRules로 본체 설정·폭발/점화 사망 콜백·삼각 얼음창 일반 분열·보조 투사체 분열·번개 구체 생성 규칙을 모았다.
- ProjectileCaster는 대상 선택·발사 경로·예비 발사 시계를 담당하고 생성은 위임한다. HitscanCaster의 번개 구체도 같은 규칙 클래스에 위임한다.
- 본체와 분열의 피해 비율, 원본 적 제외, 관통/상태 상속 범위, 보조 재분열 금지, 폭발 후 분열 순서를 유지했다. 시전마다 현재 강화 상태로 생성 규칙을 구성한다.
- 이동한 분열 콜백에 맞춰 기존 테스트 호출 위치를 수정했다. Unity CLI 컴파일·EditMode 409/409 통과. outputs/unity-spawn-rules-results.xml 확인.
- 다음 단계는 발사 경로와 형태 표시 분리다.
