# 투사체 리팩토링 1단계

- ProjectileSpawnSettings에 생성 시 위치·이동·피해·명중 효과·확률·콜백을 명명된 설정으로 모았다.
- 본체, 삼각 얼음창의 일반 분열, 보조 투사체, 번개 구체의 전투 호출부를 새 설정으로 전환했다.
- Init은 설정 값을 생성 시 복사한다. 생성 이후 설정 객체 변경이 발사된 투사체에 전파되지 않는다.
- 기존 Init은 동일한 새 초기화 경로로 위임하는 호환 진입점으로 유지했다. 기존 테스트와 이전 호출자의 기본값을 보존한다.
- 수치, 효과 상속, 풀 재사용 초기화, 콜백 실행 순서는 변경하지 않았다.
- Unity CLI 컴파일·EditMode 409/409 통과. outputs/unity-projectile-settings-results.xml 확인.
- 다음 단계: 명중 효과 처리 분리, 본체·보조·분열 생성 규칙 분리, 경로·형태 표시 분리. 이전 호출 진입점 제거는 테스트 호출부 전환 후 진행한다.
