# 전자기장 구현

- 전자기장은 자기 폭풍 선택 후 등장하며 최대 1회다. 벼락 시전 위치에 별도 지속 영역을 만든다. 원래 벼락·자기 폭풍의 타격 및 시전 주기는 유지한다. 전자기장은 별도 인술이 아니라 벼락 시전의 보조 효과이므로 기본 벼락 쿨타임을 지속 종료까지 미루지 않는다.
- 승인된 임시값: 반경 0.8 Unity 단위, 지속 3초, 1초마다 시전 시점 벼락 피해의 10%, 영역 내 이동속도 30% 감소. 최초 피해는 1초 뒤이며 3초 시점까지 최대 3회 발생한다. 피해는 정수로 내림하고 최소 1이다.
- 안정된 전장: 전자기장 선행, 최대 1회, 전자기장 고정 피해 +50 및 지속 +2초. 고전압 전장: 전자기장 선행, 최대 1회, 전자기장 피해 +400%.
- 승인된 계산 순서: `(시전 시점 벼락 피해 ×0.1 + 고정 피해 증가) × 전자기장 피해 배율`. 두 강화의 선택 순서와 무관하다. 기본 벼락 피해 25일 때 두 강화 적용 후 262.5 → 정수 피해 262, 지속 5초다.
- 영역은 적 모델 목록으로 충돌을 계산하며 같은 대상의 중복 등록을 제거한다. 경계 위 대상도 포함하고 사망한 적은 제외한다. 피해에 마비·분열·폭발·뇌전 제재 처치 연쇄를 상속하지 않는다.
- 감속은 영역마다 별도 원인을 기록한다. 겹친 영역 중 가장 강한 감속만 이동속도에 적용하며 공격 주기는 바꾸지 않는다. 영역 이탈·만료·비활성화·파괴 시 해당 영역의 감속만 제거한다. 사망 시 모델 감속 목록을 비운다. 겹친 영역의 지속 피해는 각각 발생한다.
- 영역은 풀을 사용하고 재사용 시 남은 시간·피해 주기·이전 감속 대상을 초기화한다. 원형 테두리를 표시하는 프로토타입 외형이며 전용 아트와 실제 플레이 밸런스 검증은 남아 있다.

## 검증

Unity 6000.6.3f1 CLI 컴파일·EditMode 384/384 통과, 실패·건너뜀 0. 결과: 작업 공간 outputs/unity-electromagnetic-field-results.xml. 요구사항 검증 15개 인술·168개 원문 카드·56개 런타임 매핑 통과.
