# 쿠나이 보조 발사 구현

- 확산 쿠나이: 쿠나이 강화 선행, 본체 적중 시 보조 2개 생성.
- 쿠나이 난사: 확산 쿠나이 선행, 보조 4개 추가. 합계 6개 생성.
- 보조 쿠나이 강화: 확산 쿠나이 선행, 보조 공격력 +100%. 본체 피해는 변경하지 않는다.
- 쿠나이 증폭은 확산 쿠나이와 영구 인술 레벨 13을 요구하며 본체·보조 피해 +100%인 원문 카드다. 원문 미기재인 최대 선택 횟수는 사용자 답변으로 1회 확정하여 연결했다. 영구 레벨 12에서 차단, 13에서 성공, 두 번째 선택 차단을 검증한다.
- 사용자 확정 임시값: 보조 기본 피해는 본체 현재 피해의 50%.
- 보조는 원래 적중한 대상을 다시 타격하지 않고 재분열하지 않는다. 본체 빙결·관통·폭발 등 다른 효과를 자동 전파하지 않는다.
- 방향은 본체 진행 방향의 -30~+30도에 균등 배치하며 크기는 원본 프리팹의 50%, 속도는 본체와 동일, 수명은 3초인 임시 설정이다. 난사 4방향의 전용 발사 패턴은 별도 아트·플레이 검증이 필요하다.
- 충격 쿠나이 → 뇌전 쿠나이 → 쾌속 투척 → 피뢰침과 보조 피뢰침을 연결했다. 추가 폭발도 아래 구현으로 연결했다.

## 검증

Unity 6000.6.3f1 CLI EditMode 350/350 통과, 실패·건너뜀 0. 작업 공간 outputs/unity-kunai-aux-explosion-results.xml.
보조 3개/6개 생성과 재분열 방지, 실제 쿠나이 카드 조합의 본체·보조 피해 분리를 검증한다.

## 뇌전 경로

- 충격 쿠나이는 벼락 보유 필요, 밀침 +15%. 사용자 승인 임시 기본 거리 0.2에서 0.23으로 증가한다. 폭발 쿠나이와 서로 배타다.
- 뇌전 쿠나이는 충격과 가속 필요, 속도 +100%, 확률 마비 1초. 발동률은 사용자 제공 정정에 따라 기본 100%를 사용한다. 전용 형태·아트는 남아 있다.
- 마비는 이동·공격을 멈추고 빙결과 별도 타이머를 사용한다. 재적용은 더 긴 잔여 시간으로 갱신하며 합산하지 않는다.
- 쾌속 투척은 공격력 -10%, 쿨타임 -20%. 피뢰침은 각 본체 적중에 쿠나이 피해 50%를 동일 적에게 즉시 1회 추가한다(사용자 승인 임시값).
- 보조 피뢰침은 확산·피뢰침 필요, 각 보조 적중에 보조 피해 50%를 추가한다. 추가 피해는 새 투사체·적중 이벤트를 만들지 않아 재귀 발동하지 않는다.
- 사망한 EnemyModel은 추가 피해를 무시한다. 기본 벼락 시각 효과·마비 표현·실제 플레이 밸런스 검증은 남아 있다.

## 추가 폭발

- 폭발 쿠나이와 확산 쿠나이를 모두 선택한 뒤 최대 1회 선택한다. 보조 폭발은 별도 선택 전 자동 적용하지 않는다.
- 기존 임시 폭발 수치를 재사용한다. 보조 기본 피해 배율 50%와 보조 피해 강화, 본체 폭발 피해·반경 강화를 보조 폭발에 반영한다.
- 적중으로 생성한 보조의 폭발은 재분열·재귀 벼락을 만들지 않는다. 발사 순간의 수치를 저장한다.
- 일반 보조와 추가 폭발 보조를 각각 검사하여 조건부 콜백과 기대 범위 피해를 검증한다. 전용 폭발 시각 효과와 플레이 밸런스 검증은 남아 있다.
