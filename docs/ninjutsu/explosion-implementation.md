# 화염구 폭발 구현

- 사용자 확정 임시값: 화염구 직격 피해에 더해 기본 반경 0.8 Unity 단위 안에 본체 현재 피해의 100%를 적용한다.
- 폭발 강화: 폭발 공격력 +80%, 최대 선택 3회. 직격 공격력에는 영향을 주지 않는다.
- 폭발 화염구: 폭발 강화 습득 후 등장, 반경 +80%, 최대 선택 1회.
- 일반 공격력 증감은 본체와 기본 폭발 피해에 함께 적용한다. 전용 폭발 강화는 폭발에만 적용한다.
- 폭발은 적중 시점의 이동 경로 위치를 중심으로 원형 범위를 검사한다. 범위 경계를 포함하고 같은 대상은 폭발 1회당 한 번만 타격한다.
- 죽은 적은 실제 EnemySpawner의 대상 조회에서 제외한다. 치명적인 직격으로 죽은 적에게 별도 폭발 피해를 다시 적용하지 않지만 주변 피해는 발생한다.
- 소형 얼음창에는 폭발을 자동 전파하지 않는다. 투사체 생성 시 피해·반경을 스냅샷으로 저장한다.
- 점화, 불꽃, 염폭술, 폭발 쿠나이와 자기 폭풍은 아래 추가 구현으로 연결했다. 전용 폭발 시각 효과와 다수 적 성능·밸런스 검증이 남아 있다.

## 검증

Unity 6000.6.3f1 CLI EditMode 테스트 362/362 통과, 실패·건너뜀 0. 결과는 작업 공간 outputs/unity-fireball-training-results.xml에 저장한다. 요구사항 검증 15개 인술·168개 원문 카드·46개 런타임 매핑도 통과했다.

## 폭발 쿠나이·자기 폭풍 추가

- 사용자 확정 임시값: 두 인술의 추가 폭발은 본체 피해 100%, 기본 반경 0.8을 사용한다. 최초 습득만으로 폭발하지 않고 각각의 활성화 카드를 선택해야 한다.
- 폭발 쿠나이는 화염구 보유를 요구한다. 폭발 피해 +80%는 최대 2회, 폭발 범위 +80%는 폭발 피해 강화 후 최대 1회다.
- 충격 쿠나이와 서로 배타 조건을 연결했다. 충격 쿠나이는 기본 밀침 수치가 확정되지 않아 비활성 상태로 보관한다.
- 자기 폭풍 선택 후 피해 +80%, 그 다음 범위 +80%를 각각 1회 선택할 수 있다.
- 벼락의 애니메이션/지연 적중 이벤트에서 폭발을 발생시킨다. 중복 Hit 이벤트는 무시하고 풀 재사용 시 이전 폭발 콜백을 초기화한다. 다중 콜라이더를 가진 같은 Enemy의 직격 피해도 적중 이벤트 1회당 중복되지 않도록 한다.
- 심판의 천둥은 아직 미구현이다. 자기 폭풍을 먼저 고르면 심판의 천둥이 차단되는 조건은 심판의 천둥을 연결할 때 추가해야 한다.
- 전용 폭발 시각 효과와 실제 플레이 밸런스 검증은 남아 있다.

## 화염구 충격·수련 추가

- 충격 강화는 직격 공격력 +80%, 최대 3회. 전용 ImpactDamage 효과로 폭발 공격력은 변경하지 않는다.
- 화염구 수련은 공격력 +20%, 쿨타임 -10%, 최대 1회. 일반 공격력 증가는 직격과 폭발 모두에 적용한다.
- 수련 선행조건은 최초 자료의 충격 강화와 폭발 화염구를 모두 보존한다. 추가 자료는 충격 강화만 적고 있으므로 자료 간 차이는 아직 확정되지 않았다.
- 초기 직격·폭발 피해가 각각 12일 때 충격 강화 후 21.6/12, 폭발 강화까지 고르면 21.6/21.6, 수련 후 25.92/25.92가 된다. 기존 곱연산 프로토타입 규칙이다.
- 불꽃의 추가 투사체, 염폭술의 형태 변화와 선택 제한은 남아 있다.
